# Report template

Write a compact report with the selected flow, stance, sources, assumptions,
actual persona/run count, session identity and evidence limitations.

## Hypotheses to check with real users

| Hypothesis [SYNTHETIC] | Personas/runs | Source or assumption | Real-user check |
| --- | --- | --- | --- |
| Possible barrier, missing case or contradiction | Actual IDs | Exact reference | Role, question and observable result |

Retain grounded agreement and one-off observations. Describe repeated patterns
without claiming statistical significance or prevalence. Link observed browser
screenshots separately from simulated reactions. Include held-out comparisons
only if actually performed, with any contamination disclosed.

Finish with the exact Output contract from SKILL.md. `Next:` is a suggestion,
not permission to execute another skill. Omit empty sections.
